🔒 Privacy Rules

      

        WorkSense stores metadata only — never document contents, email bodies, message bodies, passwords, or API keys. Screen capture is opt-in.
      

      
Loading privacy rules…

      

        
        
      

    


    

      
🗑️ Delete Data

      

        Deletion is permanent and limited to one concrete workspace and the selected date range. Combined/all scopes cannot be deleted in one action.
      

      

      
      
      

    

  


  

    
🧩 Workspace Classification

    

      Workspaces are separated in the database and in every query. Legacy rows are deliberately marked unclassified rather than being auto-attributed. Browsers are never permanently classified — only the current site/title is evaluated.
